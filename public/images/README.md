# 📷 Add your photos here

The memory gallery expects up to 4 photos in this folder, named:

```
memory-1.jpg
memory-2.jpg
memory-3.jpg
memory-4.jpg
```

Just drop your real photos in with those names (or edit the filenames in
`src/content.js` under `memories` to match whatever you use) and they'll
appear automatically in the "Our Beautiful Memories" section, with a
lightbox on click.

If a photo is missing, the gallery gracefully shows a soft placeholder
card with the caption instead of a broken image — so it's safe to deploy
before you've added every photo.

Tip: square-ish photos (close to 4:5) look best, and keep each file under
~500KB so the site stays fast.
