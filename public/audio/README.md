# 🎵 Add your song here

This folder is empty on purpose — no copyrighted music is bundled with this project.

To enable music:

1. Get an audio file you have the rights to use (a track you purchased/licensed,
   a royalty-free track, or your own recording).
2. Name it exactly: `raksha-bandhan-song.mp3`
3. Put it in this folder: `public/audio/raksha-bandhan-song.mp3`

The site will automatically pick it up. If the file is missing, the music
player still shows up, but it displays a small note instead of playing —
it never breaks the page.

Do **not** download the requested song ("O Neele Ambar Wale, Tere Bhi Khel
Nirale") from YouTube or similar sites without permission — that infringes
copyright. Good royalty-free sources include Pixabay Music, YouTube Audio
Library (royalty-free tracks only), or your own licensed purchase.
